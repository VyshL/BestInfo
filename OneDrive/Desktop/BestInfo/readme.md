# BestInfo

The BestInfo tool is a python application used for knowledge extraction. Furthermore, it gives in-depth information on any topic provided by a user, which can be considered

The tool enables searching for people, technical terms, or ideas and returns well-structured information from reliable sources using the official API of Wikipedia.

---

## Features
Features
Accepts any topic as input
- Retrieving title, summary, and complete detailed information
Applies to people, subjects of science, technology, and general knowledge

- Draws on a reliable and government-provided data source

---
# Tech Stack

"Python"

- wikipedia-api
---
# How It Works
1. User enters a name of topic.
2. BestInfo searches through Wikipedia using an official API.
3. If a topic is present, it finds:
- Title

- Summary

- Complete descriptive information
4. The information is presented in a readable format.
